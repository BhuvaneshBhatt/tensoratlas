# Normal-form and bridge contracts

This document records the minimal behavioral contracts introduced for TensorAtlas contract layer.

## Normal form contracts

A normal form implementation should be idempotent and stable under explicitly provided equivalence-preserving rewrites.

## Bridge contracts

Bridge round-trips should preserve the chosen canonical key for objects inside the supported domain.

## Provenance contracts

Rewrite and identity reports should expose before/after state and semantic or identity-family metadata.
