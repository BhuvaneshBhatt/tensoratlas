# Tutorial workflow outline

The main demo notebook is designed as a guided tour rather than a collection of isolated smoke tests.  It introduces tensor theory, coordinate calculus, forms, tensor-valued forms, curvature, relativity, geometric algebra, canonicalization, and debugging workflows in a single executable narrative.

Recommended reading order:

1. Coordinate and component conventions.
2. Vector calculus as tensor calculus.
3. Differential forms and exterior calculus.
4. Electromagnetic field-strength forms.
5. Tensor-valued forms and Cartan equations.
6. Curvature of the two-sphere.
7. Schwarzschild and FLRW relativity examples.
8. Abstract tensor canonicalization.
9. Orthogonal-metric geometric algebra.
10. Performance and debugging practices.
